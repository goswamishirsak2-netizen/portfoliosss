# Shirsak Goswami - Developer Portfolio Website

A modern, premium, fully responsive Frontend Developer Portfolio Website for **Shirsak Goswami**, built using pure HTML5, CSS3, and ES6+ JavaScript.

## 🚀 Live Demo & Features

![imgage alt]{https://github.com/goswamishirsak2-netizen/portfoliosss/blob/2cde5cc858ca846cce692f5cb92397a8463831e9/project-5star.png}

- **Theme**: Dark Turquoise Premium UI (`#081B1B` background, `#00D4C7` glowing accent)
- **Design System**: Glassmorphism cards, ambient particle canvas background, smooth CSS animations
- **Tech Stack**: HTML, Python, AI Automation
- **Featured Projects**:
  - 🍫 5 Star Chocolate Brand Landing Page
  - 🌐 Personal Portfolio
  - 🤖 AI & Python Automation Tool
- **Responsive Layout**: Seamless experience across Mobile, Tablet, and Desktop screens
