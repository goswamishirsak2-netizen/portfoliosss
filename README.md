# Shirsak Goswami - Developer Portfolio

A world-class, premium, fully responsive Developer Portfolio Website built strictly with **HTML5, CSS3, and Vanilla JavaScript** (no frameworks, no external libraries).

Designed with a high-end dark teal theme (`#081B1B`, `#102A2A`, `#00D4C7`, `#22D3EE`), glassmorphism, 60 FPS custom interactive cursor, micro-animations, and clean typography (*Sora* & *Poppins* fonts).

---

## 🌟 Key Features

1. **Ultra-Smooth 60 FPS Custom Cursor System**:
   - Electric turquoise inner dot locked to mouse coordinates.
   - Fluid cyan outer ring interpolated via `requestAnimationFrame` and linear interpolation (`lerp`).
   - Magnetic hover scaling on links, buttons, project cards, and input fields.
   - Ripple click effect on mouse click.
   - Auto-disabled on touch/mobile screens for native performance.

2. **Hero Section with Interactive Developer Card**:
   - Name: **Shirsak Goswami**
   - Title: **Aspiring Frontend Developer • Python Learner • AI Enthusiast**
   - Description reflecting active learning of HTML, Python, GitHub, and AI tools.
   - Custom animated 3D glass Developer Card featuring glowing icons for HTML, Python, GitHub, and Artificial Intelligence.

3. **Curated Sections**:
   - **About**: Honest, professional introduction highlighting passion for continuous learning.
   - **Skills**: Glassmorphism cards for HTML, Python, GitHub, and Artificial Intelligence.
   - **Projects**:
     - 🍫 *5 Star Chocolate Website* (Completed)
     - ⚡ *Personal Portfolio* (Currently Building)
     - 🚀 *AI & Python Showcase* (Coming Soon)
   - **Learning Journey**: Vertical timeline with glowing central line, completion checkmarks, and current AI progress milestone.
   - **Contact Section**: Info cards for Email, GitHub, LinkedIn + Submit-Only Validated Contact Form with Toast Notification.

4. **Sticky Glass Navbar & Scroll Features**:
   - Top scroll progress indicator bar.
   - Glassmorphic navigation bar with `IntersectionObserver` active section tracking.
   - Mobile responsive drawer menu toggle.
   - Scroll-to-top floating button.

## 🚀 How to Run Locally

Since this project uses pure HTML5, CSS3, and Vanilla JavaScript, no build process or package installation is required.

Simply open `index.html` in any modern browser (Chrome, Edge, Firefox, Safari) or use a local static server like VS Code Live Server.

```bash
# Optional: run a local static server
npx serve .
```
