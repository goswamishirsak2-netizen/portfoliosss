A world-class, premium, fully responsive Frontend Developer Portfolio Website designed and built from scratch using only **HTML5**, **CSS3**, and **Vanilla JavaScript** (no frameworks, no backend). Inspired by Apple, Vercel, Linear, and Framer UI design standards.

---

## ✨ Features Showcase

- 🎨 **Dark Cyan Glassmorphism Aesthetics**: Built with a sleek dark background (`#081B1B`), subtle glass cards (`backdrop-filter: blur(16px)`), ambient glow blobs, and glowing turquoise accents (`#00D4C7` & `#22D3EE`).
- ⚡ **Preloader & Smooth Animations**: Branded `<SG />` preloader screen, micro-interactions, scroll reveal effects, and button ripple animations.
- 🌌 **Dynamic Particle Background**: HTML5 Canvas animation rendering glowing nodes connected by proximity-based interactive lines.
- 💳 **3D Animated Glass Tech Hub**: An interactive visual card replacing personal photos with floating HTML5, CSS3, JavaScript, Python, and AI technology icons.
- 🎯 **Interactive UI Elements**:
  - Top scroll progress status bar.
  - Active section navigation highlighting on scroll.
  - Custom glowing cursor follower with magnetic hover state.
  - Interactive project showcase modal window.
  - Contact form UI with input validation and animated toast alerts.
  - Floating scroll-to-top button.
  - Responsive mobile glass drawer navigation menu.

## 🚀 How to Run Locally

Since this portfolio is built with pure static HTML, CSS, and Vanilla JavaScript, no build process or package installations are required!

### Option 1: Open Directly in Browser
Simply double-click `index.html` or open it with your preferred web browser.

### Option 2: Run with Python Local HTTP Server
If you prefer testing over a local server:

```bash
# Clone the repository
git clone https://github.com/goswamishirsak2-netizen/Shirsak.git

# Navigate to project folder
cd Shirsak

# Start Python HTTP Server
python -m http.server 8080
```

Now open `http://localhost:8080` in your web browser.
